## Реализовано

- Карта, страны и маршрут убраны. Вкладки: Категории, Повторение, Прогресс.
  Выбор CEFR меняет новые наборы; настройки открываются шестерёнкой.
- Поиск, 12 категорий, рекомендация с приоритетом due, продолжение последнего
  набора, «Самое нужное», избранное, свои слова и фильтры частей речи.
  Коллекции ссылаются на исходные conceptId, а не размножают их.
- Существующий Match сохранён: 4/5 пар, стабильные активные слоты, парное
  пополнение случайных освобождённых мест, 60 совпадений, milestones 20/30/60,
  120 секунд по умолчанию. Пятая ошибка завершает только включённое испытание.
  Время монотонное и активное; фон и диалог останавливают часы и скрывают поле.
- SQLite сохраняет экспозиции, ответы, первую сторону ошибочного выбора,
  distractor ID, задержку, сессии, флаги, настройки и свои слова. Стабильные ID
  обеспечивают идемпотентность. Незаконченная практика не становится победой.
  Временный сбой записи оставляет события в очереди; следующий успешный ответ
  или Retry восстанавливает в том числе показанные ранее подсказки.
- Отдельные очереди и лестницы узнавания/вспоминания 1/3/7/14/30/60 дней.
  Максимум один шаг за локальный день, только по наступившему сроку и без
  подсказки. Показ английского ответа в Match блокирует самостоятельное
  вспоминание этого значения в тот же день, сохраняя обычное узнавание.
  Cooldown — три других совпадения, приоритет ошибок ограничен и не вытесняет
  остальные слова. Маленькая очередь предлагается как recall.
- Recall показывает русский вопрос и контекст до ответа; проверяет только
  перечисленные варианты с безопасной нормализацией. Клавиатура, «Не знаю»,
  пауза в фоне, промежуточное сохранение и Retry реализованы.
- Стадии «Новое / Тренирую / Узнаю / Подтверждено позже», исторические уникальные
  подтверждения, 11 рангов Старт–Лексикон, семь одноразовых достижений,
  недельная активность и полная история с ленивым списком.
- Все показанные настройки имеют действие: ежедневная цель, бюджет 2/4/8 новых
  слов (12 в первом знакомстве), режим review, пары, таймер, испытание, звук,
  громкость, вибрация, motion, офлайн-голос, тема, увеличенный текст.
  Изменения игрового режима применяются при создании следующего раунда.
- Экспорт/импорт через Android SAF: JSON v1, предварительная проверка,
  preview, атомарное объединение, конфликт ID откатывает импорт, повторный
  импорт не размножает события/награды. Неизвестные ID сохраняются.
  Сброс только с подтверждением; на пользовательском телефоне не запускался.
- Indigo/teal, светлая и тёмная темы, собственные векторные знаки, молния и
  combo, общий момент доступности входящих пар. Анимация обновляет локальные
  слоты. Полный/спокойный/минимальный режимы и системный reduced motion.
  Длинные подписи переносятся без FittedBox, многоточий и уменьшения до микро-
  шрифта; высота одинакова для всего пула, крупный текст допускает прокрутку.
- Шесть оригинальных WAV, предзагрузка, Android SoundPool с максимумом двумя
  потоками, без await в обработчике игровых правил. TTS отбирает английские
  голоса без требования сети. Отсутствующий media engine не ломает игру.
  Новый SVG, adaptive/monochrome, legacy/round PNG для всех пяти плотностей.
